# WFDF 团队飞盘规则 2025-2028 附录 v2.0（中文校订整合版）

> 本文件由当前网页版手册内容回溯生成，作为附录中文源稿。正式适用版本以 WFDF 发布文本为准。

# 引言

本附录规则旨在对基础规则作出补充，以建立运转顺畅、便于观众观看、资源保障充分的高水平竞技赛事。当《团队飞盘规则》与本附录之间存在不一致时，以本附录为准。本规则为世界飞盘联合会（WFDF）赛事设定标准，同时也应作为非 WFDF 赛事最佳实践的指导。

具体而言，本规则应适用于以下赛事：

• 世界团队飞盘及勇气飞盘锦标赛（World Ultimate and Guts Championships）；

• 世界大师团队飞盘锦标赛（World Masters Ultimate Championships）；

• 世界团队飞盘俱乐部锦标赛（World Ultimate Club Championships）；

• 世界大师团队飞盘俱乐部锦标赛（World Masters Ultimate Club Championships）；

• 洲际锦标赛（例如泛美锦标赛、亚大洋洲锦标赛、全非洲锦标赛）；

• 世界运动会（同时适用 WFDF 和/或 IWGA 赛事主办方要求的其他调整）；

• 世界 U24 团队飞盘锦标赛（World Under-24 Championships）；

• 世界青少年团队飞盘锦标赛（World Junior Ultimate Championships）。

对于非 WFDF 赛事，可根据可用资源水平和比赛竞技水平，在基础比赛规则之上选用或修改本附录中的部分规则。非 WFDF 赛事的基本调整可以包括：

• 比赛场地表面；

• 场上队员人数；

• 场地尺寸；

• 比赛时长；以及

• 场地标线。

# 附录 A：WFDF 比赛附加规则

## A1. 比赛场地（Playing Field）

**A1.1.** 比赛场地的全部表面必须为以下任一种：

**A1.1.1.** 天然草地；

**A1.1.2.** 人工草地。

**A1.2.** 比赛场地尺寸：

**A1.2.1.** 比赛场地长一百（100）米、宽三十七（37）米。

**A1.2.2.** 中心区长六十四（64）米；中心区两端各设一个纵深十八（18）米的得分区。两个砖点分别距相应得分线十八（18）米，并位于两条边线之间的正中位置。

**A1.2.3.** 所有场地标线的宽度必须在七十五（75）毫米至一百二十（120）毫米之间，并使用无腐蚀性的材料进行标记。

**A1.3.** 必须在距场地外围边界线至少三（3）米处设置第一条限制线。比赛进行期间，参赛双方队伍的所有人员都必须位于该限制线之外。必须在距第一条限制线至少二（2）米处再设置第二条限制线。WFDF官员可以酌情扩大这些限制线与场地之间的距离。除获准进入的官员外，其他所有人员以及所有装备在比赛进行期间都必须位于第二条限制线之外。

**A1.3.1.** 使用第二条限制线时，根据规则 2.7 示意边线妨碍所采用的距离，由三（3）米增加至五（5）米。
图1：设有限制线的场地图示。

**A1.4.** 相邻比赛场地之间的最小间距必须为三（3）米。

**A1.4.1.** 如果相邻场地之间的距离小于六（6）米，比赛进行期间，每支队伍最多允许两（2）名非场上人员位于两块场地之间。除获准进入的官员外，不允许其他人员或装备位于两块场地之间。

**A1.5.** 任何缩短限制线设置距离、进一步缩短两个相邻场地之间距离，或缩小比赛场地尺寸的安排，都必须事先获得 WFDF 官员的书面批准。

**A1.6.** 为使场地能够设置在较小的比赛区域内，可以申请例外批准以缩小场地尺寸；缩小后场地最小宽度为三十五（35）米，最小长度为九十（90）米。得分区纵深以及砖点距得分线的距离可缩短，但最小为十五（15）米。

**A1.7.** WFDF 官员可以要求各队将队伍成员、非场上团队支持人员（NPTS）以及装备限制在指定区域内；相关要求可以包括仅允许位于某一侧边线，或限制在指定的较小区域内。

**A1.7.1.** 任何未登记为队员或 NPTS 的人员，均视为观众，其进入相关区域的权限受限。

**A1.8.** WFDF 官员可以指定比赛场地上方的某些特定物体不视为界外物体；如果飞盘击中这些物体，则飞盘应回到原持盘队员手中。

## A2. 装备（Equipment）

**A2.1.** 飞盘：

**A2.1.1.** 比赛中只能使用该赛事指定的官方比赛飞盘（Official Game Disc）。

**A2.1.2.** 拥有盘权的队伍可以在比赛进行期间于以下情形更换飞盘：

**A2.1.2.1.** 飞盘位于界外，且更换飞盘能够节省时间。必须将更换飞盘的行为明确告知对方队伍；

**A2.1.2.2.** 在任何比赛中断期间，但仅限于更换已经损坏的飞盘；

**A2.1.2.3.** 一个回合结束后、下一次开盘之前。

**A2.1.3.** 官员可以持有备用的官方比赛飞盘，以便在上述情况下用于更换。

## A3. 比赛开始（Start of Game）

**A3.1.** 双方队伍代表通过同时抛掷两张飞盘（以下称“掷盘决定”，toss）的方式决定谁先进行开场选择。

**A3.2.** 两张飞盘仍在空中时，其中一名代表应喊“same（相同）”或“different（不同）”。

**A3.3.** 如果两张飞盘均正面朝上或均反面朝上，则“same”获胜；否则“different”获胜。

**A3.4.** 掷盘决定应在比赛场地上进行。

**A3.5.** 比赛计时钟应在预定开赛时间，根据 WFDF 官员发出的信号开始计时。

**A3.5.1.** 只有指定的 WFDF 官员可以酌情调整开赛时间。

**A3.5.2.** 如果在完成掷盘决定后，开赛时间被调整超过十五（15）分钟，或者比赛被移至另一块场地，则赢得掷盘决定的队伍可以更改其最初选择；对方队伍随后也可以根据需要更改自己的选择。上述更改必须在调整后的开赛时间至少五（5）分钟前完成。

## A4. 比赛时长（Length of Game）

**A4.1.** 目标分：

**A4.1.1.** 首先达到十五（15）分目标分的队伍获胜。

**A4.2.** 时间上限（Time cap）：

**A4.2.1.** 如果比赛进行一百（100）分钟后仍未达到目标分，则触发时间上限。

**A4.2.2.** 触发时间上限后，比赛继续至当前回合结束。如果当前回合结束时双方均未达到十五（15）分，则在当时较高的比分上加一（1）分，形成时间上限目标分。比赛继续进行，直至有队伍达到该时间上限目标分并获胜。

**A4.2.3.** 时间上限不影响每支队伍可使用的暂停次数。

**A4.3.** 中场休息（Half Time）：

**A4.3.1.** 首支达到八（8）分中场目标分的队伍出现时，进入中场休息。

**A4.3.2.** 中场休息持续七（7）分钟。

**A4.3.2.1.** 七（7）分钟结束后，按照 A5.4 开始计算该半场第一个回合的开盘前时间。

**A4.3.2.2.** 如果时间上限在七（7）分钟中场休息期间触发，则按照 A4.2.2，视为当时的当前回合已经结束。

**A4.4.** 半场时间上限（Half Time Cap）：

**A4.4.1.** 如果比赛进行五十五（55）分钟后仍未达到中场目标分，则触发半场时间上限。

**A4.4.2.** 触发半场时间上限后，比赛继续至当前回合结束。如果该回合结束时双方均未达到八（8）分，则在当时较高的比分上加一（1）分，形成半场时间上限目标分。比赛继续进行，直至有队伍达到该目标分，随后进入中场休息。

**A4.4.3.** 半场时间上限不影响每支队伍可使用的暂停次数。

**A4.5.** 暂停：

**A4.5.1.** 每支队伍每场比赛可以使用两（2）次暂停。每次暂停持续七十五（75）秒。

**A4.6.** 回合之间、暂停期间以及中场休息期间，比赛计时钟不停止。但是，出现以下情况时比赛计时钟停止：

**A4.6.1.** 飞盘精神暂停；

**A4.6.2.** 赛事技术中断；

**A4.6.3.** 一次受伤中断或技术中断持续超过两（2）分钟后；以及

**A4.6.4.** 因恶劣天气而增加的额外比赛中断。

**A4.6.5.** 比赛重新开始时，比赛计时钟必须重新开始计时。

## A5. 时间限制（Time Limits）

**A5.1.** 必须指定一名计时员负责监控时间并发出时间警示信号。

**A5.2.** 掷盘决定：

**A5.2.1.** 双方队长必须在比赛开始至少五（5）分钟前完成掷盘决定。

**A5.2.2.** 如果在比赛开始五（5）分钟前掷盘决定仍未完成，且其中一支队伍的队长未到场，则已经到场的队长同时获得首次盘权选择权以及首先防守哪一端得分区的选择权。

**A5.2.3.** 如果双方队长均未到场，则最先到场的队长获得上述两项选择权。

**A5.3.** 每个半场开始时：

**A5.3.1.** 计时员应发出以下信号：

**A5.3.1.1.** 半场开始前六十（60）秒；

**A5.3.1.2.** 半场开始时。

**A5.4.** 一个回合开始后、下一次开盘出手并正式开始比赛之前：

**A5.4.1.** 进攻方：

**A5.4.1.1.** 自回合开始四十五（45）秒后，所有进攻方队员都应有一只脚踩在本方防守得分线上，并且在开盘出手前不得改变彼此之间的相对位置。

**A5.4.1.2.** 进攻方应确保防守方能够不受遮挡地看清所有进攻方队员。

**A5.4.1.3.** 进攻方必须在回合开始后六十（60）秒内发出准备接盘的信号。进攻方只有在所有队员均处于合法位置，且所有属于进攻方的非场上人员均已离开比赛场地后，才可以合法发出准备就绪信号。

**A5.4.1.4.** 如果进攻方未能按时合法发出准备就绪信号，对方应在开盘出手前示意“pre-pull time limit violation（开盘前时间限制违例）”；比赛必须停止，直至双方队伍均确认该违例，否则该示意无效。

**A5.4.2.** 防守方：

**A5.4.2.1.** 防守方必须在回合开始后七十五（75）秒内完成开盘，或在进攻方合法发出准备就绪信号后十五（15）秒内完成开盘，以两者中较晚的时限为准。

**A5.4.2.1.1.** 开盘出手之前，所有属于防守方的非场上人员都必须离开比赛场地。如果防守方的非场上人员仍未离场，则必须在进攻方触盘之前示意该违例，随后应按防守方发生“Offside（越线）”违例的方式恢复比赛。

**A5.4.2.2.** 如果防守方未能按时完成开盘，对方应示意“pre-pull time limit violation（开盘前时间限制违例）”。该违例必须在进攻方触盘之前示意。

**A5.4.3.** 混合组：

**A5.4.3.1.** 在混合组比赛中，如适用，负责作出人员比例选择的队伍必须在回合开始后十五（15）秒内表明本回合将采用四（4）名女性对位队员，还是四（4）名男性对位队员。

**A5.4.3.2.** 相关队伍必须以口头方式并配合相应手势，表明场上人员比例：“ratio: female matching（人员比例：女性对位）”或“ratio: male matching（人员比例：男性对位）”。

**A5.4.3.3.** 如果相关队伍未能按时表明场上人员比例，则沿用上一回合的人员比例；如果是在一个半场开始时，则默认使用三（3）名女性对位队员和四（4）名男性对位队员的人员比例。

**A5.4.4.** 计时员应发出以下信号：

**A5.4.4.1.** 回合开始四十五（45）秒时（向进攻方发出剩余十五秒警示）；

**A5.4.4.2.** 回合开始六十（60）秒时（向防守方发出剩余十五秒警示）；

**A5.4.4.3.** 回合开始七十五（75）秒时，或进攻方合法发出准备就绪信号十五（15）秒后，以两者中较晚的时刻为准（此时比赛必须开始）。

**A5.4.5.** 在“开盘前时间限制违例”之后重新开始比赛：

**A5.4.5.1.** 如果进攻方是违规队伍，开盘照常进行；之后持盘队员必须按照规则 7.9、7.10、7.11 或 7.12 建立轴心点，随后比赛应尽快在该位置，按照规则 20.3 所规定的暂停后恢复程序重新开始（除非规则 7.8 适用）。

**A5.4.5.2.** 如果防守方是违规队伍，开盘照常进行；接盘队伍随后可以让飞盘在无人触碰的情况下落地，并选择将其按已示意“Brick（砖点）”处理，在砖点恢复比赛。无需验盘。

**A5.4.6.** 如果必须重新开盘——包括因有争议的“Offside（越线）”/“False Start（抢跑）”违例而重新开盘——或者开盘因时间限制违例而延迟：

**A5.4.6.1.** 不允许换人，除非符合规则 19.1；

**A5.4.6.2.** 不允许使用暂停；

**A5.4.6.3.** 进攻方必须在违例示意后十五（15）秒内发出准备就绪信号；开盘必须在违例示意后三十（30）秒内出手，或在进攻方合法发出准备就绪信号十五（15）秒内出手，以两者中较晚的时限为准。

**A5.5.** 如果暂停发生在一个回合开始后、开盘之前，则暂停结束时：

**A5.5.1.** 该暂停会使从回合开始到开盘之间允许使用的时间增加七十五（75）秒。

**A5.5.2.** 自回合开始七十五（75）秒后，计时员应发出暂停结束信号，此后开始执行 A5.4 所规定的时间限制与信号。

**A5.6.** 如果暂停发生在开盘之后、该回合结束之前，则暂停结束时：

**A5.6.1.** 自进攻方示意暂停起，进攻方有七十五（75）秒确定静止位置并准备恢复比赛。

**A5.6.1.1.** 如果进攻方尚未准备好恢复比赛，防守方可以喊“delay of game（拖延比赛）”；如果拖延继续，防守方可以示意“Violation（违例）”。违例示意后，持盘队员必须在正确位置建立盘权，其他所有进攻方队员必须停止移动并留在当时位置，直至完成验盘。防守方可以继续移动，直到即将进行验盘为止。

**A5.6.2.** 防守方必须在暂停开始后九十（90）秒内完成验盘，或在所有进攻方队员都已确定各自位置后十五（15）秒内完成验盘，以两者中较晚的时限为准。

**A5.6.2.1.** 如果防守方仍未完成验盘，进攻方可以喊“delay of game（拖延比赛）”；如果拖延继续，进攻方可以示意“Violation（违例）”。违例示意后，防守方必须停止移动并留在当时位置，直至完成验盘（规则 9.4 可能适用）。

**A5.6.3.** 计时员应发出以下信号：

**A5.6.3.1.** 暂停开始四十五（45）秒时（向进攻方发出剩余三十秒警示）；

**A5.6.3.2.** 暂停开始六十（60）秒时（向进攻方发出剩余十五秒警示）；

**A5.6.3.3.** 暂停开始七十五（75）秒时（向防守方发出剩余十五秒警示）；

**A5.6.3.4.** 暂停开始九十（90）秒时，或所有进攻方队员均已确定位置十五（15）秒后，以两者中较晚的时刻为准（此时比赛必须开始）。

**A5.7.** 因示意或讨论而停止比赛后：

**A5.7.1.** 十五（15）秒后，如果问题仍未解决，双方各一名队长应尝试协助解决讨论。

**A5.7.1.1.** 四十五（45）秒后，如果问题仍未解决，则该次比赛动作视为“有争议（contested）”。飞盘必须回到最后一名没有争议的持盘队员手中。

**A5.7.1.2.** 如果双方队伍之间存在显著语言障碍，WFDF 官员可以额外给予十五（15）秒，以解决问题并重新开始比赛。

**A5.7.2.** 一（1）分钟后，比赛必须重新开始。

**A5.7.3.** 比赛停止四十五（45）秒后，计时员应发出信号；如果讨论仍未解决，此后每十五（15）秒重复发出一次信号。

**A5.8.** 攻防转换后以及开盘后：

**A5.8.1.** 除《团队飞盘规则》8.5.1 所规定的时间限制外，以下情况还适用二十（20）秒时间限制：

**A5.8.1.1.** 开盘后，飞盘一旦停止；以及

**A5.8.1.2.** 攻防转换位置在界外时，飞盘一旦停止。

**A5.8.1.3.** 如果在二十（20）秒内无法合理取得飞盘（例如飞盘远离场地边界，或需要穿过人群），负责取盘的队员可以请求另一张飞盘；在进攻方队员收到新飞盘之前，任何拖延计时或预读秒均暂停。

**A5.9.** 如果在某项时间限制正在计时期间示意技术中断或受伤中断，则在处理相关问题期间，或者直至受伤队员离开比赛场地为止，该时间限制暂停计时。

**A5.10.** 计时员发出信号的首选方式应为使用哨声，并可辅以口头信息和手势；具体程序应遵循《WFDF赛事总监手册》（WFDF Tournament Director's Manual）中的规定。

**A5.11.** 如果使用一连串哨声表示时间限制，则只有在最后一声哨音开始响起时，才视为已经达到该时间限制。

**A5.12.** 如果某队选择对时间违例进行示意，则必须喊“Violation”，并应使用第14号手势。

## A6. 混合组（Mixed Division）

**A6.1.** 赛事必须明确采用以下哪一种人员比例规则，以决定某个回合使用四（4）名女性对位队员和三（3）名男性对位队员，还是三（3）名女性对位队员和四（4）名男性对位队员。

**A6.1.1.** 所有 WFDF 赛事——包括所有国家队赛事、俱乐部赛事、洲际赛事和特定年龄组赛事——均使用人员比例规则 A。

**A6.2.** 人员比例规则 A（“规定比例”规则，prescribed ratio）：

**A6.2.1.** 比赛开始时，在第一次掷盘决定之后，再进行一次额外的掷盘决定，由获胜方选择第一回合的场上人员比例。第二和第三回合的人员比例必须与第一回合相反；第四和第五回合必须与第一回合相同。此后每两个回合改变一次比例的模式持续至比赛结束（中场休息不影响这一交替顺序）。

**A6.2.2.** 与人员比例规则 A 配套使用时，所有 WFDF 赛事还必须采用“规定开盘（prescribed pull）”规则：

**A6.2.2.1.** 如果某回合的人员比例为四（4）名女性对位队员，则该回合开始时必须由一名女性对位队员执行开盘；

**A6.2.2.2.** 如果某回合的人员比例为四（4）名男性对位队员，则该回合开始时必须由一名男性对位队员执行开盘；

**A6.2.2.3.** 如果违反 A6.2.2.1 或 A6.2.2.2，则应按照规则 7.5，将其作为防守方“Offside（越线）”违例处理。

**A6.3.** 人员比例规则 B（“得分区决定”规则，end zone decides）：

**A6.3.1.** 比赛开始时，在第一次掷盘决定之后，再进行一次额外的掷盘决定，由获胜方选择哪一个得分区为“得分区 A（End zone A）”，另一端则为“得分区 B（End zone B）”。上半场每个回合开始时，位于得分区 A 一侧的队伍必须选择场上人员比例。下半场则改为每个回合开始时，由位于得分区 B 一侧的队伍选择场上人员比例。

**A6.4.** 比赛开始时，双方队长必须讨论计划采用何种方法，以便更容易识别场上人员的对位关系。首选方式应包括：

**A6.4.1.** 如果某回合的人员比例为四（4）名女性对位队员，则进攻方所有女性对位队员都应站在得分线上，并使用“人员比例：女性对位（Personnel Ratio: Female Matching）”手势；

**A6.4.2.** 如果某回合的人员比例为四（4）名男性对位队员，则进攻方所有男性对位队员都应站在得分线上，并使用“人员比例：男性对位（Personnel Ratio: Male Matching）”手势；

**A6.4.3.** 相应手势应保持五（5）秒，并且最迟必须在发出开盘准备就绪信号后立即完成。

## A7. 队伍（Teams）

**A7.1.** 每场比赛，每支队伍必须指定一（1）名或两（2）名队员担任队长，并指定一（1）名或两（2）名队员担任飞盘精神队长。

**A7.1.1.** 队长必须是有资格参加该场比赛的队伍成员，并被指定代表本队，在赛前、赛中及赛后代本队参与决策。

**A7.1.2.** 飞盘精神队长必须是有资格参加该场比赛的队伍成员，并被指定在整个赛事期间随时与对手、队友、教练以及比赛或赛事官员处理、讨论和解决飞盘精神相关问题。

**A7.2.** 队伍可以配备一名或多名教练协助本队。教练是不具备参加该场比赛资格的人员，因此视为非场上团队支持人员。如果一支队伍有一（1）名以上教练，则每场比赛必须指定其中一（1）名教练代表本队，在赛前、赛中及赛后代本队参与决策。所有教练都应遵守飞盘精神。

**A7.3.** 每个回合，队伍必须有七（7）名可上场队员。混合组队伍每个回合必须同时有四（4）名女性对位队员和四（4）名男性对位队员可供上场。

**A7.3.1.** 如果一支队伍不符合 A7.3 的要求，该队必须失去一次暂停，并且该回合的开始时间延迟七十五（75）秒。

**A7.3.2.** 如果该队已没有剩余暂停，则必须判给对方队伍一（1）分，并且该回合的开始时间延迟七十五（75）秒。

**A7.3.3.** 如果双方队伍均不符合 A7.3 的要求，则双方均按照 A7.3.1 受到处罚，直至其中一队满足 A7.3 的要求，或者 A7.3.4 开始适用。

**A7.3.4.** 如果自一场比赛或一个回合开始时间起二十（20）分钟后，一支队伍仍未达到 A7.3 的要求，则该队必须弃权该场比赛。

**A7.3.5.** 弃权的队伍除记录一次弃权外，还记录该场比赛失利；对方记录胜利。该场比赛不记录具体比分。

**A7.3.6.** 如果双方均弃权，则双方都记录该场比赛失利。

**A7.3.7.** 所有弃权情况都将由赛事规则小组（TRG）审查。如果认定弃权的目的是在赛事中获取竞技优势，则将考虑对该队实施处罚。

**A7.3.8.** 弃权比赛不进行飞盘精神评分（SOTG scores）。

**A7.3.8.1.** 一支队伍必须在其计划进行的比赛中有超过 50% 的比赛获得飞盘精神评分，才有资格参与飞盘精神奖项评选。

**A7.4.** 如果一个回合已经开始，而某队场上人数并非恰好七（7）人，或者没有使用正确的场上人员比例，则对方可以示意“Violation（违例）”并停止比赛；或者违规队伍可以按照规则 20.4 使用一次暂停处理该问题。

**A7.4.1.** 违规队伍必须自行决定移除或补入哪一名/哪些队员。如果需要补入队员，对方队伍可以进行相同人数的换人。

**A7.4.2.** 对方队伍必须选择以下任一恢复方式：按已经示意一次暂停的方式恢复比赛（依规则 20.3），或者重新开始整个回合。

**A7.4.3.** 如果 A7.4 违例是在已经得分之后、下一次开盘之前示意，对方队伍可以选择取消该次得分并重新开始该回合。

## A8. 语言（Language）

**A8.1.** 读秒以及所有规则示意必须使用英语。

**A8.1.1.** 如果有队员在口头沟通方面存在明显困难，双方队长必须在比赛开始前讨论合适的替代沟通方式。

## A9. 竞技比赛义务（Competitive Play）

**A9.1.** 在任何一个回合中，参与比赛的队员都必须努力为本队完成得分和/或阻止对方得分。

**A9.2.** 如果出现违反 A9.1 的情况，必须向赛事规则小组成员报告。

## A10. 非场上人员提供建议（Advice From Non-players）

**A10.1.** 在任何比赛中断期间，如果实际情况允许，本队队长、飞盘精神队长或教练可以在未被请求的情况下进入场地，鼓励本队队员更改其示意；但只有当更改示意后的结果会对本队不利时，才允许这样做。

**A10.2.** 比赛中断期间，队伍可以使用一名非场上人员担任翻译，协助双方沟通。翻译人员应本着善意，尽可能准确地进行翻译。翻译人员应在自己是在进行翻译时，以及改为对某个示意提供建议时，分别向双方队伍明确说明。如果讨论中使用翻译，则适用 A5.7.1.2 所规定的时间限制。

## A11. 技术的使用（Use of Technology）

**A11.1.** 如果有相关照片或视频画面可供查看，队员可以查看与某次示意有关的照片或视频画面；但不得为此不合理地延误比赛。

**A7.3.1.** 如果边线上的队伍成员根据照片或视频画面提供建议，则只有在被询问时才可以提供该建议（A10.1 适用的情况除外），并且只有当建议结果会对本队不利时才可以提供。如果某名队伍成员根据照片或视频画面掌握的信息将使本队获益，则其应与边线上的对方队伍成员讨论这些信息，或邀请直接参与该次比赛动作的队员自行查看画面。

**A11.2.** 队员不得使用任何形式的电子通信设备与其他队员或队伍成员进行通信。

## A12. 犯规与违例示意（Foul and Violation Calls）

**A12.1.** 如果一场比赛出现大量示意，尤其是大量示意持续存在争议，队长或比赛官员应尽快将情况告知赛事技术主管或赛事规则小组（TRG）。应向 TRG 报告的规则问题包括：

**A12.1.1.** 反复超过解决示意争议的时间限制；

**A12.1.2.** 队员反复故意主动制造身体接触；

**A12.1.3.** 队员和/或非场上团队支持人员未持续待在限制线之外。

**A12.2.** 如果 TRG 获悉有关某支队伍或某名个人行为表现的担忧，TRG 成员可以在赛事期间与该队伍或个人讨论这些问题。

**A12.2.1.** 是否需要对队伍或个人采取进一步措施，由 TRG 决定。

**A12.3.** 如果某支队伍反复出现危险动作，或出现一次性质极其严重的危险动作，双方队长和飞盘精神队长应会面讨论如何处理。处理方式可以包括：

**A12.3.1.** 示意飞盘精神暂停；

**A12.3.2.** 讨论避免今后再次发生危险动作的方法；

**A12.3.3.** 改变该次比赛动作的处理结果，即使该结果并不符合某一条具体规则；

**A12.3.4.** 不允许相关队员继续参加该场比赛；

**A12.3.5.** 联系 TRG 成员，请求一名 WFDF 官员或 TRG 成员到场观察该场比赛剩余部分。

## A13. 飞盘精神暂停（Spirit Stoppage）

**A13.1.** 如果某队队长、飞盘精神队长、指定的 WFDF 官员或 TRG 成员认为任一队伍或双方队伍未遵守（或存在未能遵守的风险）飞盘精神（SOTG），可以示意“Spirit Stoppage（飞盘精神暂停）”。该示意只能在以下时机作出：

**A13.1.1.** 在某次使比赛停止的示意或其他比赛中断发生之后、飞盘重新验盘之前；

**A13.1.2.** 一个回合开始之后、随后一次开盘之前。

**A13.2.** 飞盘精神暂停期间，双方队伍均不得进行战术讨论。双方所有队伍成员应在场地中央共同围成一个“飞盘精神圆圈（spirit circle）”。

**A13.3.** 在飞盘精神圆圈之外，双方队长和飞盘精神队长必须单独讨论当前所有与遵守飞盘精神有关的问题，确定纠正这些问题所需采取的行动，然后将达成的共识告知飞盘精神圆圈中的所有人员。

**A13.4.** 飞盘精神暂停既不影响各队可用暂停次数，也不受各队可用暂停次数影响。

**A13.5.** 按照 A4.6，飞盘精神暂停期间比赛计时钟必须停止。

**A13.6.** 如果飞盘精神暂停是在比赛进行期间示意，暂停结束后，队员必须回到示意飞盘精神暂停之前各自大致所在的位置。

## A14. 赛事技术中断（Tournament Technical Stoppages）

**A14.1.** 赛事官员可以因任何原因示意赛事技术中断。

## B1. 参赛名单（Rosters）

**B1.1.** 每支队伍在该赛事的比赛参赛名单中，至少必须登记十四（14）名队员。

**B1.1.1.** 如果取得该队所属国家协会、教练团队（如有）以及所有队员的书面同意；对于青少年队伍，则取得所有队员或其监护人的书面同意；并且在报名阶段事先取得 WFDF 官员的书面批准，则该队可以仅以十二（12）名队员作为比赛参赛名单的最低登记人数参加赛事。

**B1.1.2.** 对于洲际锦标赛，每支队伍在该赛事的比赛参赛名单中至少必须登记十二（12）名队员。

**B1.1.3.** 混合组队伍的参赛名单中还必须至少有七（7）名女性对位队员和七（7）名男性对位队员。

**B1.1.4.** 如果队伍在赛事期间因伤失去已登记队员，该队仍获准继续参加赛事。

**B1.2.** 每支队伍的参赛名单最多可以登记二十六（26）名队员。

**B1.3.** 队员人数的最高和最低限制不适用于非场上团队支持人员（例如随队嘉宾、教练或其他支持人员）；这些人员可以随队登记参加赛事。

**B1.4.** 因严重医疗状况取消队员参赛资格：

**B1.4.1.** 如果赛事首席医疗官（CMO）认定某名队员因严重医疗状况不应重返比赛，则该队员自此被取消比赛资格，直至 CMO 后续认定该队员已经获得医学许可，可以重返比赛。

**B1.4.2.** 在赛事期间，CMO 至少每二十四（24）小时对因医疗原因被取消比赛资格的队员重新评估一次是否可以重返比赛；CMO 也可以酌情更频繁地进行评估。

**B1.4.3.** CMO 的决定不得由其他医疗服务人员推翻。

**B1.4.4.** 赛事规则小组负责执行本政策。

**B1.4.5.** CMO 应迅速与赛事规则小组沟通，通知其有关医疗取消资格以及恢复医学许可的情况。

**B1.5.** 如果发现某队曾让未列入参赛名单的人员参加比赛，队长或比赛官员应尽快将此情况告知赛事技术主管或赛事规则小组（TRG）。是否需要对相关队伍或个人采取进一步措施，由 TRG 决定。

## B3. 排名标准与平分判定（Ranking Criteria and Tie Breakers）

**B3.1.** 小组循环赛结束后，根据各队获胜场次对每个小组内的所有队伍进行排名。

**B3.2.** 如果有队伍战绩相同，则使用以下排名标准打破平分。

**B3.3.** 每一项排名标准都用于对所有仍处于平分状态的队伍进行整体排序，而不是仅用于确定其中排名最高的一支队伍。

**B3.3.1.** 应用某一项排名标准后，如果所有相关队伍仍然平分，则进入下一项标准。

**B3.3.2.** 如果并非所有队伍仍然平分，但其中一个或多个子组仍处于平分状态，则将这些子组从当前排名中分离出来。每个子组分别重新进行排名，并从第一项排名标准开始重新判断。

**B3.4.** 排名标准依次为：

**B3.4.1.** 获胜场次，仅计算平分队伍彼此之间的比赛；

**B3.4.2.** 弃权场次最少；

**B3.4.3.** 得失分差，仅计算平分队伍彼此之间的比赛；

**B3.4.4.** 得失分差，计算对阵所有共同对手的比赛；

**B3.4.5.** 场均得分，仅计算平分队伍彼此之间的比赛；

**B3.4.6.** 场均得分，计算对阵所有共同对手的比赛；

**B3.4.7.** 每支队伍指定一名队员，在标准尺寸比赛场地上从得分线后方朝远端砖点投掷一张飞盘。投掷顺序通过随机方式确定，例如掷盘决定或其他随机方式。按照每张飞盘最终停止位置与砖点之间的距离，由近到远对各队排名。

## B4. 恶劣天气规则（Inclement Weather Rules）

**B4.1.** 预防性调整赛程：

**B4.1.1.** WFDF 官员应至少提前二十四（24）小时监测每个比赛日的天气预报。

**B4.1.2.** 如果预计某个比赛日会出现恶劣天气，官员可以调整当天赛程，并应最迟在调整后新的当日开赛时间十二（12）小时前通知所有队长。

**B4.1.3.** 调整后的赛程可以包括提前开赛、缩短比赛间休息时间、降低时间上限和/或降低目标分。只有在比赛很可能受到中断、且后续比赛日几乎没有空间补回延误比赛时（例如赛事最后一天），才应缩短比赛时长。

**B4.1.4.** 在极端情况下，调整后的赛程可以预先取消部分比赛，以为更重要的比赛重新安排时间腾出空间。

**B4.1.5.** 如果比赛发生延误，也可以允许当日比赛更晚结束。

**B4.2.** 雷电：

**B4.2.1.** 现场风险识别：

**B4.2.1.1.** 在预计会出现雷暴的比赛日，官员应获取实时天气观测信息，例如在线天气雷达或无线电天气警报，以预判雷暴抵达比赛场地的时间。

**B4.2.1.2.** 如果雷暴即将到来，官员应告知所有队长和现场官员比赛可能暂停，并再次说明 WFDF 关于风险识别和应对的规则。条件允许时，队长和官员也应向队员及场地上的其他人员说明正确的风险识别和应对程序。

**B4.2.1.3.** 如果观察到闪电或听到雷声，WFDF 官员应计算闪电（光）与雷声（声）之间的时间差。如果时间差小于三十（30）秒，则说明雷击距离小于十（10）公里，必须立即清空比赛区域。

**B4.2.1.4.** 如果比赛场地配备雷电监测技术，则 B4.2.1.3 不适用；WFDF 官员可以根据场地方官员提供的建议采取行动。

**B4.2.1.5.** 如果任何人发现毛发竖起、听到噼啪声，或听到电子设备出现静电噪声，则雷击可能即将发生，应立即警示附近所有人员。

**B4.2.2.** 对已识别风险的应对：

**B4.2.2.1.** 一旦识别到雷电风险，官员必须立即通知双方队长。比赛必须立即暂停，飞盘留在原地。队长收到暂停通知后发生的任何比赛动作均视为无效。

**B4.2.2.2.** 所有人员都应前往适当的避雷场所。

**B4.2.2.3.** 如果人员暴露在雷暴环境中且无法前往适当避雷场所，应蜷缩成球状，最好位于地面低洼处，并摘除所有金属配饰。

**B4.2.3.** 恢复比赛：

**B4.2.3.1.** 除非正在使用雷电监测技术，否则必须自最后一次观察到闪电或雷声起经过三十（30）分钟，且 WFDF 官员正式通知允许返回场地之后，队员才可以重新进入比赛场地。

**B4.3.** 高温天气：

**B4.3.1.** 每个比赛日，WFDF 官员都应判断极端高温天气是否会对队员造成与高温有关的疾病和伤害风险。

**B4.3.2.** 在预计会出现极端高温的比赛日，WFDF 官员应通知所有队长和现场官员，并传达适当的高温应对方法。队长和官员也应将这些方法告知队员及场地上的其他人员。

**B4.3.3.** 出现极端高温时，可以按以下方式调整比赛：

**B4.3.3.1.** 在回合之间增加额外中断，让队员休息并补充水分；

**B4.3.3.2.** 重新安排比赛时间，避免在一天中最炎热的时段比赛；

**B4.3.3.3.** 缩短比赛时长并降低目标分上限；

**B4.3.3.4.** 如果 TRG / TTD / CMO 认定环境过于极端，可以暂停或取消比赛。

**B4.4.** 空气质量：

**B4.4.1.** 每个比赛日，WFDF 官员都应使用当地资源监测赛事所在地的空气质量健康指数（AQHI）。

**B4.4.2.** 如果 AQHI 为 3 或以下，比赛照常进行。

**B4.4.3.** 如果 AQHI 为 4–6：

**B4.4.3.1.** 每个半场增加一次官方中断。对于目标分为 15 分的比赛，第一次中断在某队达到 4 分时进行；第二次中断在某队达到 12 分时或触发时间上限时进行。对于采用其他目标分的比赛，上述分数应按比例调整。

**B4.4.3.2.** 每次官方中断都会使开盘前的时间延长三（3）分钟。

**B4.4.4.** 如果 AQHI 为 7 或以上：

**B4.4.4.1.** 所有比赛必须暂停，直至 AQHI 降至 7 以下。应要求队员和赛事工作人员在条件允许的情况下进入室内避护。

## B5. 暂停或取消比赛（Suspended or Cancelled Play）

**B5.1.** 指定的 WFDF 官员如果有合理理由，可以暂停或取消任何比赛。相关理由必须告知受到影响的队伍。

**B5.1.1.** 如果 WFDF 官员决定暂停或取消比赛，应按照以下规则确定比赛如何继续以及如何确定适当的比赛结果。

**B5.1.2.** 如果比赛在某个回合进行期间暂停，WFDF 官员应记录暂停时飞盘所在的位置。

**B5.1.3.** 如果比赛在一次得分完成后、随后的开盘之前暂停，则进攻方可以重新选择上场阵容，即使暂停发生时进攻方已经对原上场阵容完成示意。

**B5.2.** 重新安排赛程：

**B5.2.1.** 在比赛暂停期间，所有在场的队长必须与 WFDF 官员会面，讨论重新安排比赛的方案。在条件允许时，应重新安排比赛。为了完成重新安排，可以降低时间上限和目标分上限。

**B5.3.** 恢复已暂停比赛：

**B5.3.1.** 如果重新安排赛程后可以继续此前暂停的比赛，则在可能的情况下，比赛应从清空场地时飞盘大致所在的位置，按照规则 20.3 所规定的暂停后恢复程序重新开始。

**B5.3.2.** 一旦获准重新进入比赛场地，双方队伍在恢复比赛前有十（10）分钟热身时间。

**B5.4.** 确定暂停或取消比赛的结果：

**B5.4.1.** 如果重新安排赛程后仍无法继续已经暂停的比赛，或者比赛被取消，则必须按照以下规则确定比赛结果：

**B5.4.1.1.** 对于被暂停的比赛，如果已经进行至少一半比赛时间，或者某队已经取得至少目标分的一半，则当时领先的队伍判为获胜。如果当时比分相同，则向前回溯，以上一个回合得分之前处于领先的一方为获胜方。

**B5.4.1.2.** 对于不符合 B5.4.1.1 的暂停比赛，如果其中一队取得的破发得分多于对方，则破发得分较多的队伍判为获胜。

**B5.4.1.2.1.** 如果某队在一个回合开始时为防守方，并最终赢得该回合得分，则记为一次破发得分（break）。

**B5.4.1.3.** 在第一阶段小组赛中，如果 B5.4.1.1 和 B5.4.1.2 均不适用，则赛前确定的较高种子队伍判为获胜。

**B5.4.1.4.** 在后续阶段小组赛及决赛阶段，如果 B5.4.1.1 和 B5.4.1.2 均不适用，则由赛事规则小组决定该场比赛判为平局，还是由当时排名较高的队伍获胜；作出该决定时，应考虑第一阶段小组赛结果以及适用的 WFDF 平分判定规则。

**B5.5.** 比赛取消优先级：

**B5.5.1.** 因天气或其他突发问题，WFDF 可能需要调整赛程和/或比赛。在这种情况下，WFDF 将根据比赛重要性决定取消哪些比赛。以下标准按照比赛重要性从高到低排列：

**B5.5.1.1.** 可能影响未来“综合运动会（Multi-Sport）”赛事参赛资格的比赛，例如世界运动会或奥运会；

**B5.5.1.2.** 淘汰赛，按以下顺序：决赛、半决赛、铜牌赛、四分之一决赛/半决赛资格赛（Pre-Semi-Finals）、其他淘汰轮次（四分之一决赛资格赛/16 强赛）；

**B5.5.1.3.** 决定第 5/6 名以及第 7/8 名的排位赛；

**B5.5.1.4.** 第 8 名以下队伍的淘汰或排位比赛。在可能的情况下，应尽量避免最终名次出现并列，并优先避免较高名次的并列；也可以结合各队在整个赛事中已完成的比赛场次数进行考虑；

**B5.5.1.5.** 第一阶段小组赛（Initial Pool games）；

**B5.5.1.6.** Power Pool 比赛（Power Pool games）。

## B6. 比赛官员的职责（Tasks of Game Officials）

**B6.1.** 比赛官员分为两类：支持人员（Support Staff）和比赛顾问（Game Advisors）。

**B6.2.** 支持人员：

**B6.2.1.** 支持人员可以通过可见或可听的信号向队员提供信息，从而协助比赛顺利进行。

**B6.2.2.** 支持人员的基本职责包括：

**B6.2.2.1.** 记录比分；

**B6.2.2.2.** 记录已使用的暂停；

**B6.2.2.3.** 对比赛、中场休息和暂停进行计时；

**B6.2.2.4.** 按照 WFDF《团队飞盘规则》附录“时间限制（Time Limits）”发出时间限制信号。

**B6.2.3.** 比赛官员的其他职责可以包括：

**B6.2.3.1.** 记录队员数据统计；

**B6.2.3.2.** 记录飞盘精神评分以及最有价值队员提名；

**B6.2.3.3.** 向观众说明场上作出的示意及其处理结果；

**B6.2.3.4.** 在队员提出请求时，向其提供纸质版 WFDF《团队飞盘规则》；

**B6.2.3.5.** 执行任何可以由非场上人员承担的职责，包括在被询问时，就场地线判定提供观察视角（“Line Assistants”，场地线协助员）。

**B6.2.4.** 只有在双方队长共同邀请，或者正在进行讨论且需要咨询相关支持人员的双方涉事队员共同邀请时，支持人员才可以进入比赛场地区域。

**B6.2.5.** 支持人员不得通过作出任何示意或决定来干预正在进行的比赛，包括：

**B6.2.5.1.** 作出犯规/违例示意；

**B6.2.5.2.** 作出场地线判定；

**B6.2.5.3.** 因某队未正确响应时间警示而停止比赛；

**B6.2.5.4.** 终止场上讨论；

**B6.2.5.5.** 告诉队员应当作出什么示意。

**B6.2.6.** 支持人员的存在并不免除队员自行作出并解决所有示意的责任。

**B6.3.** 比赛顾问：

**B6.3.1.** 比赛顾问的主要角色和职能按优先级依次为：

**B6.3.1.1.** 向队员和观众提供信息，帮助比赛顺畅进行；

**B6.3.1.2.** 协助队员讨论示意；

**B6.3.1.3.** 在被询问时提供规则建议；

**B6.3.1.4.** 在被询问时提供对示意的观察视角；

**B6.3.1.5.** 向 TRG 提供信息。

**B6.3.2.** 比赛顾问的具体职责为：

**B6.3.2.1.** 赛前与双方队伍代表举行会议，说明比赛顾问的角色以及任何赛事专用规则；

**B6.3.2.2.** 密切监控各项时间限制，并鼓励队伍遵守这些时间限制及相关规则；

**B6.3.2.3.** 密切监控限制线，并鼓励队伍遵守有关限制线的规则；

**B6.3.2.4.** 密切关注各队是否发生“Offside（越线）”/“False Start（抢跑）”，并鼓励队伍遵守相关规则；

**B6.3.2.5.** 在被询问时，就任何示意提供不具有约束力的观察视角，包括但不限于“Down（落地）”“Out（界外）”“Foul（犯规）”和“Travel（走步）”；

**B6.3.2.6.** 在被询问时澄清规则；

**B6.3.2.7.** 必要时参与队员之间的场上讨论，帮助其推动讨论并形成决定；

**B6.3.2.8.** 必要时讨论对反复违反特定规则行为的担忧；

**B6.3.2.9.** 按照 A13.1 示意飞盘精神暂停；

**B6.3.2.10.** 必要时调解双方队伍之间的场外讨论；

**B6.3.2.11.** 针对涉及 WFDF《行为政策》（Conduct Policy）的事件发出警告；

**B6.3.2.12.** 将涉及 WFDF《行为政策》的事件提交 TRG；

**B6.3.2.13.** TRG 可以指定特定比赛顾问担任临时纪律执行人员（Acting Disciplinary Authorities）；这些比赛顾问可以按照 WFDF《行为政策》的规定，在比赛期间执行处罚。

**B6.3.3.** 只有在比赛顾问对某次比赛动作中实际发生的情况清楚且明显确定时，才可以提供不具有约束力的观察视角。

**B6.3.3.1.** 一旦队员请求比赛顾问提供观察视角，相关队员必须立即解决讨论，否则应将该示意按“有争议（contested）”处理。

**B6.3.3.2.** 如果队员不接受比赛顾问提供的观察视角，应说明理由。

**B6.3.4.** 比赛顾问只能在比赛中断期间进入比赛场地，但进入时无需事先征得队长或队员批准。

**B6.3.5.** 比赛顾问的存在并不免除队员自行作出并解决所有示意的责任。

# 附录 C：比赛服装要求

## C1. 目的（Purpose）

**C1.1.** 本比赛服装要求的首要目的，是区分双方队伍的队员，并识别每一名具体队员，从而使队员、官员和观众能够正确跟进并理解比赛。

**C1.2.** 本要求同时旨在保障队员安全与舒适，并维护比赛公平。

**C1.3.** 此外，更高质量的比赛服装应借助 WFDF 赛事所提供的媒体传播和观众展示机会，向世界传递本项运动更好的公众形象。

**C1.4.** 本要求力求在实现上述首要目的的同时，将队员为满足服装要求所承担的成本降到最低。如果资源允许，鼓励队伍在最低要求基础上进一步提高服装标准，以最大限度提升本项运动的整体收益。

**C1.5.** WFDF 要求队伍在为 WFDF 赛事设计比赛服装时，同时考虑规则要求以及本项运动的公众形象。

**C1.6.** WFDF 保留要求某支队伍或某名队员修改或更换比赛服装上的文字或图案，以及更换或移除某件比赛服装用品的权利。

## C2. 一般要求（General）

**C2.1.** 一套比赛服装至少必须包括：能够覆盖胸部和腹部的上衣，以及能够覆盖下躯干和大腿上部的下装。

**C2.2.** 如果一件连体服装同时满足本规则对上述两件独立服装的要求，则可以将其作为完整比赛服装使用。

**C2.3.** 每场比赛，每支队伍至少必须携带两套能够明显区分的比赛上衣；判断是否能够区分时还应考虑色觉障碍人士的辨识需求。

**C2.4.** 所有比赛服装用品都必须具备专业赛事水准，不得对本项运动的形象造成负面影响。

## C3. 主队与客队（Home and Away）

**C3.1.** 赛事赛程可以为每场比赛指定“主队（home）”和“客队（away）”。

**C3.2.** WFDF 可以为特定比赛指定队伍服装颜色。

**C3.3.** 如果赛事赛程没有指定主客队，则双方队长应在赛前通过掷盘决定或其他公平方式确定哪支队伍为主队。

**C3.4.** 主队拥有优先选择比赛上衣颜色的权利。

**C3.5.** 在抵达比赛场地之前，一支队伍可以提前告知对方哪套上衣是本队的“主队上衣”；一旦作出该说明，该队即受此决定约束。

## C4. 比赛上衣（Shirts）

**C4.1.** 同一支队伍的所有队员都必须穿着颜色和图案一致的比赛上衣；袖长可以不同。

**C4.2.** 每场比赛中，每支队伍的每一名队员都必须被指定一个 0 至 99（含）之间且不与队友重复的整数号码。

**C4.3.** 队员在该场比赛所穿上衣必须标有其号码，且号码只能使用阿拉伯数字表示；号码为 0 至 9（含）时，可以选择在前面增加一个 0。

**C4.4.** 号码必须缝制或印刷在上衣背面。号码中的每个数字高度至少为十六（16）厘米，笔画宽度至少为三（3）厘米。

**C4.4.1.** 号码也可以同时出现在上衣其他位置。

**C4.4.2.** 号码应使用纯色，其与上衣主色之间的对比度应至少达到 6:1。

**C4.5.** 号码必须能够从远处清楚辨认，整体必须为单一颜色，并与上衣背景颜色存在明显差异。

**C4.6.** 不得有任何叠加图案或文字遮挡号码。

## C5. 下装（Pants）

**C5.1.** 本规则所称“下装”，是指至少覆盖下躯干和大腿上部的任何服装。

**C5.2.** 同一支队伍的所有队员必须穿着颜色和图案一致的下装。

**C5.3.** 下装左腿前侧可以缝制或印刷号码；该号码必须与队员比赛上衣上的号码一致。

## C6. 可选元素（Optional Features）

**C6.1.** 如果该队为国家队，比赛服装还可以包含代表该国家的国际奥委会三字母国家/地区代码和/或该国国旗。

**C6.2.** 比赛上衣可以印有队员姓名。

**C6.3.** 比赛服装可以印有赞助商名称或标志。

## C7. 内搭衣物（Undergarments）

**C7.1.** 队员可以在比赛服装内穿着其他衣物，以防止受伤、应对温度或阳光等因素。

**C7.2.** WFDF 认为，如果内搭衣物外露部分为黑色、白色或与主要比赛服装颜色一致，将有助于提升本项运动的整体形象。

## C8. 手套（Gloves）

**C8.1.** 队员可以佩戴手套，但手套不得以任何方式损坏飞盘，也不得在飞盘表面留下任何残留物。

**C8.2.** 队员不得为了增强握力，在手部涂抹任何可能在比赛过程中转移到飞盘表面的物质。

## C9. 头部装备（Headgear）

**C9.1.** 队员可以佩戴帽子、球帽或其他头部装备，以防晒、应对天气、防止受伤或满足个人舒适需要。

**C9.2.** 如果同一支队伍的队员佩戴帽子，则所有帽子的款式和颜色必须相近。就本规则而言，遮阳帽（visor）与其他帽子视为款式相近。

## C10. 袜子（Socks）

**C10.1.** 如果同一支队伍的队员穿着长袜，WFDF 认为统一长袜将有助于提升本项运动的整体形象。

## C11. 鞋类（Footwear）

**C11.1.** 队员必须穿鞋或球靴。队员之间的鞋类无需在任何方面保持一致。

**C11.2.** 鞋底上的任何鞋钉或凸纹从鞋底突出的高度不得超过二十（20）毫米，并且不得存在任何锋利边缘。

## C12. 队员其他比赛服装要求（Additional Uniform Requirements for Players）

**C12.1.** 队员不得穿戴任何会对其他队员造成危险的物品。WFDF 认为全金属鞋钉和石膏固定物属于危险物品。

**C12.2.** 队员不得穿戴任何通过显著增加其身体外形或占据空间而获得竞技优势的物品。

**C12.3.** 队伍比赛服装必须符合 WFDF《社会表达政策》（Social Expression Policy）。

**C12.4.** 比赛服装用品不得展示与赛事或队伍无关的商业标志，或其他无关符号；符合 WFDF《社会表达政策》的情况除外。

**C12.5.** 队员、替补人员和队伍官员不得使用任何放大其声音的设备。

**C12.6.** 如果某些道具可能对本项运动的形象造成负面影响，队员、替补人员和队伍官员可能被要求停止使用这些道具，或限制其摆放/使用位置。

## C13. 教练与支持人员（Coaches and Support Staff）

**C13.1.** 教练和支持人员在边线区域必须穿着适当服装；其风格最好与本队相近，但颜色最好能够与本队队员明显区分。

**C13.2.** 如果教练或支持人员的服装例如与相关 WFDF 官员的服装容易混淆，则在条件允许的情况下，可以要求其更换服装。

# 附录 D：WFDF 参赛资格与参赛名单指南

## D1. 队伍参赛资格——一般规定

**D1.1.** 参加 WFDF 批准的锦标赛并进行报名，必须具备 WFDF 会员资格。只有处于良好会员状态的正式会员组织、组织类会员以及准会员组织，才可以登记参赛队伍。

**D1.2.** 参赛名单中的所有队员都必须是所属国家协会中处于良好会员状态的成员，并满足该国家协会对其提出的其他全部要求。

**D1.3.** “国家协会（National Federation）”是指获得 WFDF 认可、代表某一国家开展团队飞盘运动的 WFDF 会员组织。

**D1.4.** 在同一项 WFDF 赛事中，同一名队员不得代表一支以上队伍参赛。

**D1.5.** 队伍参赛名单在提交前，必须由代表该队的国家协会官员审核。该官员必须在名单上会签，以表明其已经审核名单，并确认名单符合队员参赛资格要求。

**D1.6.** 如果 WFDF 认为某份已提交的参赛名单不能充分代表该队原本应代表的国家，WFDF 保留宣布该名单无效的权利。

## D2. 队伍参赛资格——国家队参赛名单

**D2.1.** 面向国家队的 WFDF 世界团队飞盘锦标赛包括：

**D2.1.1.** WFDF 世界团队飞盘锦标赛（WUC）；

**D2.1.2.** WFDF 世界青少年团队飞盘锦标赛（WJUC）；

**D2.1.3.** WFDF 世界 U24 团队飞盘锦标赛（WU24）；

**D2.1.4.** WFDF 世界大师团队飞盘锦标赛（WMUC）。

**D2.2.** 就各组别的国家队参赛名单资格而言，符合以下相应标准的国家将被视为“规模较小的团队飞盘社群（small Ultimate community）”。对于青少年赛事，计算时只统计该组别中具备参赛资格的已登记队员人数：

**D2.2.1.** 混合组：根据赛事前一个日历年度的 WFDF 普查数据，该国国家协会（团队飞盘协会、飞盘协会或类似组织）登记的女性团队飞盘队员不超过一百五十（150）人，或者男性团队飞盘队员不超过一百五十（150）人；

**D2.2.2.** 公开组：根据赛事前一个日历年度的 WFDF 普查数据，该国国家协会登记的男性团队飞盘队员不超过一百五十（150）人；

**D2.2.3.** 女子组：根据赛事前一个日历年度的 WFDF 普查数据，该国国家协会登记的女性团队飞盘队员不超过一百五十（150）人；

**D2.2.4.** U20 混合组：根据赛事前一个日历年度的 WFDF 普查数据，该国国家协会登记的 U20 女性团队飞盘队员不超过七十五（75）人，或者 U20 男性团队飞盘队员不超过七十五（75）人；

**D2.2.5.** U20 公开组：根据赛事前一个日历年度的 WFDF 普查数据，该国国家协会登记的 U20 男性团队飞盘队员不超过七十五（75）人；

**D2.2.6.** U20 女子组：根据赛事前一个日历年度的 WFDF 普查数据，该国国家协会登记的 U20 女性团队飞盘队员不超过七十五（75）人；

**D2.2.7.** 该国成为国家协会的时间不足十六（16）年。

**D2.3.** 队员类别——国家队参赛名单中的所有队员必须属于以下类别之一：

**D2.3.1.** 法定公民（Legal Citizen）：如果队员持有该国政府签发的护照或具有同等法律效力的文件，则视为“法定公民”。

**D2.3.2.** WFDF 公民（WFDF Citizen）：如果队员在赛事举办年度的 1 月 1 日之前至少四十（40）个月已经迁居该国，并且在这四十（40）个月中有超过 75% 的时间居住在该国，则也视为“WFDF 公民”。

**D2.3.3.** 非公民居民（Resident Non-Citizen）：如果队员在赛事举办年度的 1 月 1 日之前至少十二（12）个月已经迁居该国，并且在这十二（12）个月中有超过 75% 的时间居住在该国，则视为“非公民居民”。

**D2.4.** 队伍名单构成——一支国家队的参赛名单可以包括：

**D2.4.1.** 任意数量的法定公民或 WFDF 公民；

**D2.4.2.** 最多四（4）名非公民居民。

**D2.5.** 队伍名单构成——规模较小的团队飞盘社群：

**D2.5.1.** 来自规模较小团队飞盘社群的队伍，可以在参赛名单中额外增加一（1）名非公民居民。

**D2.5.2.** 对于来自规模较小团队飞盘社群的队伍，D2.3.3 中非公民居民所要求的居住时间缩短为六（6）个月。

## D3. 队伍参赛资格——俱乐部队参赛名单

**D3.1.** WFDF 世界团队飞盘俱乐部锦标赛包括：

**D3.1.1.** WFDF 世界团队飞盘俱乐部锦标赛（WUCC）；

**D3.1.2.** WFDF 世界大师团队飞盘俱乐部锦标赛（WMUCC）；

**D3.1.3.** WFDF 世界高级大师团队飞盘俱乐部锦标赛（WGMUCC）。

**D3.2.** 俱乐部队伍的参赛资格根据相应国家协会的规则确定。

**D3.3.** 俱乐部队名不得包含任何经 WFDF 判断可被合理视为冒犯性或不适当的措辞。

## D4. 队员参赛资格——性别

**D4.1.** 队员要具备参加以下 WFDF 比赛组别的资格，必须满足相应规定标准。

**D4.2.** 跨性别运动员的参赛资格由 WFDF《跨性别政策》（Transgender Policy）管理。

**D4.3.** 混合组——任何具备公开组参赛资格的队员都可以作为男性对位队员参赛；任何具备女子组参赛资格的队员都可以作为女性对位队员参赛。

**D4.4.** 公开组——所有队员均具备参加各项赛事公开组比赛的资格。

**D4.5.** 女子组——所有女性对位队员均具备参加各项赛事女子组比赛的资格。

## D5. 队员参赛资格——年龄

**D5.1.** 队员要具备参加以下 WFDF 比赛组别的资格，必须满足相应规定标准。

**D5.2.** 混合组、公开组和女子组——队员在赛事结束所在日历年度内必须年满十六（16）岁。

**D5.3.** 大师组：

**D5.3.1.** 以女性对位队员身份参加大师组的队员，在赛事结束所在日历年度内必须年满三十（30）岁；

**D5.3.2.** 以男性对位队员身份参加大师组的队员，在赛事结束所在日历年度内必须年满三十三（33）岁。

**D5.4.** 高级大师组：

**D5.4.1.** 以女性对位队员身份参加高级大师组的队员，在赛事结束所在日历年度内必须年满三十七（37）岁；

**D5.4.2.** 以男性对位队员身份参加高级大师组的队员，在赛事结束所在日历年度内必须年满四十（40）岁。

**D5.5.** 超级大师组：

**D5.5.1.** 以女性对位队员身份参加超级大师组的队员，在赛事结束所在日历年度内必须年满四十五（45）岁；

**D5.5.2.** 以男性对位队员身份参加超级大师组的队员，在赛事结束所在日历年度内必须年满四十八（48）岁。

**D5.6.** U24 组——参加该组别的队员，在赛事结束所在日历年度内必须年满十四（14）岁，同时不得达到二十四（24）岁或以上。

**D5.7.** 青少年 U20 组——参加该组别的队员在赛事结束所在日历年度内必须：

**D5.7.1.** 年满十四（14）岁；或者

**D5.7.2.** 年满十二（12）岁，并取得该队员父母或监护人、主教练以及国家协会的全部批准；并且

**D5.7.3.** 不得达到二十（20）岁或以上。

**D5.8.** U17 组——参加该组别的队员，在赛事结束所在日历年度内必须年满十二（12）岁，同时不得达到十七（17）岁或以上。

**D5.9.** U14 组——参加该组别的队员，在赛事结束所在日历年度内必须年满十（10）岁，同时不得达到十四（14）岁或以上。

**D5.10.** U11 组——参加该组别的队员，在赛事结束所在日历年度内必须年满八（8）岁，同时不得达到十一（11）岁或以上。

## D6. 参赛名单信息（Roster Details）

**D6.1.** 所有赛事提交的参赛名单都必须包含每名队员的以下信息：

**D6.1.1.** 全名；

**D6.1.2.** 比赛号码（0–99）；

**D6.1.3.** 出生日期；

**D6.1.4.** 性别；

**D6.1.5.** 国籍。

**D6.2.** 指定的 WFDF 官员可以要求队伍提供能够证明上述参赛名单信息的材料。

## D7. 参赛名单资格——洲际锦标赛（AAUC、AOUC、PAUC）

**D7.1.** WFDF 洲际锦标赛包括：

**D7.1.1.** WFDF 全非洲团队飞盘锦标赛（AAUC）；

**D7.1.2.** WFDF 亚大洋洲团队飞盘锦标赛（AOUC）；

**D7.1.3.** WFDF 泛美团队飞盘锦标赛（PAUC）。

**D7.2.** 为鼓励参赛，WFDF 允许“国家队”或“俱乐部队”参加洲际锦标赛。参赛队伍必须被明确指定为“国家队”或“俱乐部队”，国家协会在批准参赛名单时必须使用对应的参赛资格标准。

**D7.3.** 如果某个国家在同一赛事的同一组别派出一（1）支以上队伍，则最多只有一（1）支队伍可以使用“国家队”参赛资格规则；该组别中该国其他所有队伍必须使用“俱乐部队”参赛资格规则。

## D8. 例外批准（Exemptions）

**D8.1.** 在特殊情况下，各国家协会或队伍可以向 WFDF 团队飞盘委员会申请豁免 D 节所列《参赛资格与参赛名单指南》的部分要求。

# 附录 E：种子、赛程与赛事席位

## E1. 国家队赛事种子排序（按组别）

**E1.1.** 使用该赛事上一届比赛的最终名次，确定前八（8）号种子队伍。

**E1.2.** 对未包含在 E1.1 中的其余国家，使用以下依据确定种子排序：

**E1.2.1.** 该赛事上一届比赛的最终名次；

**E1.2.2.** 如果某个国家未参加上一届相关赛事，则使用世界团队飞盘排名（World Ultimate Ranking）。

**E1.3.** 根据 E1.2 得分为零（0）的所有国家，通过随机抽签排列在种子名单末端。

**E1.4.** 欧洲队伍重新排序：

**E1.4.1.** WUC：依据最近一届欧洲团队飞盘锦标赛成绩，重新排列欧洲队伍，同时保持这些欧洲队伍相对于非欧洲队伍的原有相对位置。

**E1.4.2.** WJUC：依据最近一届欧洲 U20 青少年团队飞盘锦标赛成绩，重新排列欧洲队伍，同时保持这些欧洲队伍相对于非欧洲队伍的原有相对位置。

## E2. 俱乐部队赛事种子排序（按组别）

**E2.1.** 对每个国家参赛的所有队伍（例如 USA1、USA2、USA3），按照该国国家协会提供的排序进行种子排位；如果国家协会未提供意见，则依据用于取得 WFDF 赛事参赛资格的选拔赛事结果进行排序。

**E2.2.** 欧洲队伍重新排序：使用最近一届欧洲团队飞盘俱乐部锦标赛结果对欧洲队伍进行排序（例如 EUR1、EUR2、EUR3）。同一国家的队伍之间应继续保持 E2.1 所确定的相对顺序。

**E2.3.** 使用该赛事上一届比赛的最终名次进行排序，将各国队伍放入上一届由同一国家队伍取得的相应名次位置。对于欧洲队伍，则将其放入上一届由欧洲队伍取得的相应名次位置。

**E2.4.** 对无法根据 E2.3 确定种子位置的队伍，由团队飞盘委员会依据其掌握的最佳信息进行种子排序。

## E3. 小组种子分配（半随机种子，Semi-Random Seeding）

**E3.1.** 各小组采用传统的“蛇形（snake）”编号方式进行种子分配。例如：
| A组 | B组 | C组 | D组 |
|---:|---:|---:|---:|
| 1 | 2 | 3 | 4 |
| 8 | 7 | 6 | 5 |
| 9 | 10 | 11 | 12 |
| 16 | 15 | 14 | 13 |
| 17 | 18 | 19 | 20 |

**E3.2.** 如果各小组队伍数量不相等，队伍数量较少的小组应首先对应拥有 1 号种子的组，其次对应拥有 2 号种子的组，以此类推。例如：
| A组 | B组 | C组 | D组 |
|---:|---:|---:|---:|
| 1 | 2 | 3 | 4 |
| 8 | 7 | 6 | 5 |
| 9 | 10 | 11 | 12 |
| 16 | 15 | 14 | 13 |
|  |  | 17 | 18 |

**E3.3.** 每个小组的 1 号种子根据队伍排名名单直接放置。

**E3.4.** 随后从排名名单中取接下来的“n”支队伍，其中“n”=小组数量，并将这“n”支队伍随机抽入接下来的“n”个种子位置。

**E3.4.1.** 当赛事设有四（4）个或以上小组时，“n”始终至少为 4，且最多为小组数量的 50%（前提是仍有足够多尚未放置的队伍）。

**E3.5.** 重复 E3.4，直至所有队伍均完成分组。

**E3.6.** 如果某一批队伍的放置结果导致在世界级赛事的同一小组中，同一国家出现超过两（2）支队伍；或者在洲际赛事的同一小组中，同一国家出现超过一（1）支队伍，WFDF 可以调整该批队伍的随机抽签结果以避免这种情况。为实现该目标，队伍只能在该次随机抽签所对应的“n”支队伍抽签池内移动（见 E3.4）。

**E3.7.** 对于 WU24 和 WJUC 赛事，如果小组数量超过两（2）个，并且某一批队伍的放置结果导致同一地区在一个小组中出现超过三（3）支队伍，WFDF 可以调整该批队伍的随机抽签结果以避免这种情况。为实现该目标，队伍只能在该次随机抽签所对应的“n”支队伍抽签池内移动（见 E3.4）。

## E4. 国家队赛事参赛名额（WUC、WU24、WJUC、WMUC）

**E4.1.** 对于每一个组别，只要赛事容量允许，所有就该组别表达参赛意向的 WFDF 国家协会，均将在每项赛事的该比赛组别中获得一（1）个参赛名额。

**E4.2.** 如果赛事对队伍数量或参赛人数设有容量限制，WFDF 将按照以下标准及其先后顺序减少向国家协会提供的参赛名额。任何国家协会在同一比赛组别中最多获得一（1）个名额。对于 E4.2.1 和 E4.2.3，如果向所有国家协会完整执行相应标准将超过赛事容量，WFDF 可以使用当时最近的 WFDF 世界团队飞盘排名进一步限制所提供的名额数量。

**E4.2.1.** 如果某国家协会的队伍在上一届相关世界国家队赛事的某个比赛组别中获得前九（9）名（包括并列），则该国家协会在该比赛组别中获得一（1）个名额。

**E4.2.2.** 对于主办协会未通过 E4.2.1 获得名额的每个组别，主办协会均获得一（1）个名额。

**E4.2.3.** 对于未通过 E4.2.1 或 E4.2.2 获得名额的国家协会：在从本国所属洲际赛事相应组别的最终名次中，剔除来自已经依据 E4.2.1 和 E4.2.2 获得名额国家的队伍后，如果该国家协会的队伍在剩余队伍中排名前三（3）（包括并列），且该洲际赛事在本赛事开始前十（10）个月以前已经结束，则该国家协会在该比赛组别中获得一（1）个名额。

**E4.2.4.** 对于未通过 E4.2.1、E4.2.3 或 E4.2.3 获得名额的国家协会，在赛事仍有容量的前提下，根据赛事开放报名时的 WFDF 世界团队飞盘排名，该协会将在自行选择的一个组别中获得一（1）个名额。

**E4.2.5.** 在依据 E4.2.1、E4.2.3、E4.2.3 和 E4.2.4 首次发布名额后，各组别剩余的名额、国家协会退回的名额，或因队伍未在赛事报名截止日期前完成报名而被取消的名额，将按照候补名单分配给国家协会。

**E4.2.6.** 每个比赛组别都应建立候补名单，将其余已经表达参赛意向的队伍，按照赛事开放报名时的 WFDF 世界团队飞盘排名顺序列入候补名单。任何国家如果接受了 E4.2.4 所规定的单一名额，则该国在其他组别候补名单中的所有剩余队伍，都应被移至相应候补名单的末端，并在这些相同情形的队伍之间按 WFDF 世界团队飞盘排名排序。

## E5. 俱乐部队赛事参赛名额（WUCC）

WFDF 按照以下标准及其先后顺序分配名额。如果向所有国家协会完整执行某项标准会超过赛事容量，WFDF 可以使用最近的 WFDF 世界团队飞盘排名限制所提供的名额数量。

**E5.1.** 如果某国家协会参加了上一届 WUC 的某个比赛组别，则该国家协会在 WUCC 的相应比赛组别中获得一（1）个名额。

**E5.2.** 对每个比赛组别，上一届相关世界俱乐部赛事中该组别最终排名前三（3）的国家，各获得一（1）个名额。

**E5.3.** 对于主办国尚未通过 E5.1 或 E5.2 获得名额的每个比赛组别，主办国获得一（1）个名额。

**E5.4.** 对每个比赛组别，如果最近一届洲际锦标赛该组别冠军所属国家尚未通过 E5.1 或 E5.2 获得至少一（1）个名额，则该国获得该组别的一（1）个名额。

**E5.5.** 任何未通过 E5.1、E5.2、E5.3 或 E5.4 获得至少一（1）个名额的国家协会，将获得一（1）个名额，其具体组别由该协会自行决定。

**E5.5.1.** 如果此前已经提供的名额使某一组别被认定为“已满（full）”，WFDF 可以限制该国家协会依据 E5.5 选择该组别。

**E5.5.2.** 如果某国家协会拒绝其根据 E5.1、E5.2、E5.3 和 E5.4 获得的全部名额，则在适用 E5.5 时，将该协会视为未通过 E5.1、E5.2、E5.3 或 E5.4 获得名额的协会。

**E5.6.** 如果某个比赛组别被纳入某国家协会上一日历年度的全国锦标赛，或计划纳入该协会本日历年度的全国锦标赛，则该国家协会在该组别中获得一（1）个名额。

**E5.7.** 对于未通过 E5.6 获得某组别名额的国家协会，如果该协会有队伍参加上一届洲际赛事的该比赛组别，则该协会在该组别中获得一（1）个名额。如果该组别与该国家协会依据 E5.5 选择的名额组别相同，则不再提供此名额。

**E5.8.** 各组别的额外名额按照上一届相关世界俱乐部赛事中各国家的最终名次依次提供，从第 4 名国家开始。

**E5.9.** 各组别的额外名额还将依据名额分配流程开始时的 WFDF 世界排名依次提供给各国家协会，从世界排名第 1 的国家开始。

## E6. 大师俱乐部队赛事参赛名额（WMUCC）

WFDF 按照以下标准及其先后顺序分配名额。如果向所有国家协会完整执行某项标准会超过赛事容量，WFDF 可以使用最近的 WFDF 世界团队飞盘排名限制所提供的名额数量。

**E6.1.** 如果某国家协会参加了上一届 WMUC 的某个比赛组别，则该国家协会在 WMUCC 的相应比赛组别中获得一（1）个名额。对于 WMUCC 中设置、但上一届 WMUC 未设置的其他组别，各国家协会在每个相应比赛组别中均获得一（1）个名额。

**E6.2.** 对每个组别，上一届 WMUC 中该组别最终排名前三（3）的国家，各获得一（1）个名额。对于其他组别，则由最近的 WFDF 世界团队飞盘排名中排名前三（3）的国家，在每个组别各获得一（1）个名额。

**E6.3.** 未通过 E6.1 或 E6.2 获得名额的国家协会，如果某个组别被纳入该协会上一日历年度的全国锦标赛，或计划纳入该协会本日历年度的全国锦标赛，则将在该组别获得一（1）个名额。

**E6.4.** 任何在所有组别中均未通过 E6.1、E6.2 或 E6.3 获得至少一（1）个名额的国家协会，将获得一（1）个名额，其具体组别由该协会决定。

**E6.4.1.** 如果某一具体组别已经达到容量上限，WFDF 可以限制该国家协会的组别选择。

**E6.5.** 各组别的额外名额按照上一届相关世界俱乐部赛事中各国家的最终名次依次提供，从第 4 名国家开始。

## E7. 赛程编排规则（Scheduling Rules）

在为 WFDF 世界级赛事编排赛程时，官员应考虑以下标准。越靠前的条款，其重要性越高。

**E7.1.** 根据整体赛程结构，赛事中的所有队伍都必须拥有相同的夺冠路径。例如，除非所有队伍都有类似机会获得相同的轮空待遇，否则不得让某支队伍自动“轮空（bye）”进入赛事更后面的轮次。

**E7.1.1.** 如果赛事第一阶段各小组的队伍数量不相等，可以作为例外处理。在这种情况下，队伍数量较多的小组可能需要进行额外一场循环赛，并且与队伍数量较少的小组相比，较大组中可能会有额外一支队伍在进入下一阶段前被淘汰。

**E7.2.** 除非存在特殊情况，各队两场比赛之间至少应有六十（60）分钟间隔。

**E7.3.** 同一支队伍在同一天内不得参加超过两（2）场比赛。

**E7.3.1.** 如果存在重大赛程限制，或者天气问题使赛事需要通过调整赛程才能公平完成，则可以突破 E7.3。例如，与其取消四分之一决赛，可以在赛事最后一天安排四分之一决赛、半决赛和决赛。在这种情况下，赛程必须满足以下要求：

**E7.3.1.1.** 同一支队伍在一项赛事中不得有超过一（1）天需要单日参加三（3）场比赛；

**E7.3.1.2.** 在可能的情况下，某队只有在第三场比赛的对手同样是在参加当天计划的第三场比赛时，才应被安排单日第三场比赛；

**E7.3.1.3.** 在可能的情况下，参加单日第三场比赛的双方队伍当天此前应经历相同的赛程，即比赛和轮空发生在相同时间段。

**E7.4.** 赛程应尽量避免同一支队伍在某一天的最后一个时间段比赛，又在第二天的第一个时间段比赛。

**E7.5.** 赛程应尽量避免同一支队伍连续三（3）天被安排在赛事当天第一个时间段比赛。

**E7.6.** 赛程应尽量避免同一支队伍在同一天既参加第一个时间段的比赛，又参加最后一个时间段的比赛。

**E7.7.** 根据赛事规模、可用场地数量以及安排半决赛所带来的赛程收益，可以不在赛程中设置铜牌赛（第 3/4 名比赛）。在这种情况下，两支队伍均获得铜牌并列赛事第 3 名，并参加最终颁奖仪式。用于世界团队飞盘排名时，每个相关国家获得第 3 名与第 4 名排名积分的平均值。

## E8. 世界团队飞盘排名（World Ultimate Rankings）

**E8.1.** 世界团队飞盘排名依据最近四年 WFDF 团队飞盘赛事中，每个国家在各比赛组别中成绩最好的队伍最终名次计算。

**E8.2.** 所有符合资格的赛事及组别中，每支参赛队伍的世界团队飞盘排名积分按以下公式计算：

积分 =（最高积分 ÷ 组别队伍数量）×〔（组别队伍数量 − 队伍名次）+ 1〕。

**E8.2.1.** 对俱乐部赛事，一个国家只有最终名次最高的队伍获得积分。计算“组别队伍数量”时，同一国家名次更低的队伍从参赛队伍列表中移除。

**E8.2.2.** 一个国家的世界团队飞盘排名积分，是该国在所有符合资格的赛事/组别中取得的全部积分之和。

**E8.2.3.** 世界团队飞盘排名使用所有符合资格赛事最近一次举办的结果进行计算。

**E8.3.** 符合资格的赛事、组别与最高积分：
| 赛事 | 组别 | 最高积分 |
|---|---|---:|
| WUC / WUCC | O / W / X | 48 |
| WBUC | O / W / X | 48 |
| WBUC | MO / MW / MX | 24 |
| WBUC | 其他年龄限制组别 | 12 |
| WU24 / WJUC | O / W / X | 36 |
| WMUC / WMUCC | MO / MW / MX | 24 |
| WMUC / WMUCC | 其他大师年龄组别 | 12 |
| 洲际赛事（Continentals） | O / W / X | 24 |
| 洲际赛事（Continentals） | 年龄限制组别* | 12 |
\* 洲际赛事中的年龄限制组别，只有在相同组别此前已经在 WJUC、WMUCC、WMUC（草地赛事）或 WBUC（沙滩赛事）中设置过时，才具备排名积分资格。

**E8.4.** 对任何具体赛事而言，“最近的世界团队飞盘排名”是指该赛事进行名额分配流程时有效的世界团队飞盘排名。

## E9. 种子排序与名额调整（Adjustments to Seeding and Bids）

**E9.1.** 在特殊情况下，团队飞盘委员会有权调整按照 E 节规则生成的种子排序和参赛名额。

**E9.2.** 如果团队飞盘委员会作出调整，WFDF 必须公开发布调整理由。

# 附录 F：手势

## F1. 手势的目的（Purpose of Hand Signals）

**F1.1.** 用于向其他队员、比赛官员、替补人员、队伍工作人员或观众说明直接参与该次比赛动作的队员作出了什么示意。注意：所有示意的责任仍由队员承担。

## F2. 手势的使用（Use of Signals）

**F2.1.** 手势既可以由直接参与该次比赛动作的队员作出，也可以由听到该示意的其他队员或非场上人员（例如官员）作出。

**F2.2.** 非场上人员只有在场上队员已经作出示意后，才可以相应做出手势。

**F2.3.** 在以下示意发生后，非场上人员还应使用第 22 号手势，指出是哪一支队伍作出了该示意：Foul（犯规）、Violation（违例）、Retracted（撤回）、Time-out（暂停）、Spirit Stoppage（飞盘精神暂停）以及 Stoppage（比赛中断）。

## 手势 1–24

1. Foul / 犯规： 一只手臂平直伸出，另一只前臂横切该手臂。

2. Violation / 违例： 双手举过头顶形成 V 字，双手握拳。

3. Goal / 得分： 双臂完全伸直向上举起，掌心相对。

4. Contest / 争议： 双拳在胸前相碰，手背朝外。

5. Accepted / 接受： 双前臂向身体前方伸出，肘部贴近躯干，掌心向上。

6. Retracted / 撤回： 双臂向下伸展，在身体前方交叉扫动。

7. In/Out-of-bounds / 界内/界外： 一只手臂伸直，以平掌指向比赛场地内或场地外。

8. Disc down / 飞盘落地： 手臂伸直，食指向下约四十五（45）度。

9. Disc up / 飞盘在空中： 肘部向下，前臂竖直，食指向上。

10. Pick / 阻挡： 双臂抬起，肘部弯曲，双拳朝向头部。

11. Travel / 走步： 双手握拳，手腕绕垂直圆圈旋转。

12. Marking Infraction / 防盘违规： 双臂向身体两侧伸展，掌心向前。

13. Turnover / 攻防转换： 右臂向身体前方伸出，掌心向上，再旋转至掌心向下。

14. Timing Violation / 时间限制违例： 用张开的手掌拍击头部。

15. Pulling Violation / 开盘违例： 双臂在头顶交叉形成 X 字，双手握拳。

16. Time-out / 暂停： 用双手，或一只手与飞盘，组成 T 字。

17. Spirit Stoppage / 飞盘精神暂停： 双手组成倒 T 字。

18. Stoppage / 比赛中断： 双手相扣举过头顶，双臂弯曲。

19. Personnel Ratio: Male Matching / 人员比例：男性对位： 双手托在头后，肘部向外。

20. Personnel Ratio: Female Matching / 人员比例：女性对位： 双臂向身体两侧伸展，双手握拳。

21. Play has stopped / 比赛已停止： 双臂伸直，在头顶交叉挥动。

22. Who made the call / 谁作出示意： 双臂直伸，指向被该队防守的得分区。

23. Did not affect the play / 未影响比赛动作： 张开手掌举过头顶，前后扫动。

24. Match Point / 赛点： 双臂伸直指向左上方，掌心向下。

4. 媒介与格式；允许技术性修改。 许可方授权您在目前已知或今后产生的所有媒介与格式中行使被许可权利，并进行为此所必要的技术性修改。许可方在可能范围内放弃和/或同意不主张任何权利或权限，以禁止您为行使被许可权利而进行必要的技术性修改，包括为规避有效技术措施而进行的必要技术性修改。就本公共许可而言，仅进行第2(a)(4)节所授权的修改，不会因此产生演绎材料。

5. 后续接收者（Downstream recipients）。

A. 许可方的要约——许可材料。 许可材料的每一位接收者，都会自动收到许可方按照本公共许可条款和条件行使被许可权利的要约。

B. 不得增加后续限制。 如果额外或不同的条款或条件，或者有效技术措施，会限制任何许可材料接收者行使被许可权利，则您不得对许可材料提出或施加这些条款、条件或技术措施。

6. 不构成认可（No endorsement）。 本公共许可中的任何内容均不构成、也不得解释为许可您声称或暗示您本人或您对许可材料的使用，与许可方或第3(a)(1)(A)(i)节规定的其他应获署名者存在关联，或者获得其赞助、认可或官方地位。

b. 其他权利（Other rights）

1. 人格权，例如保护作品完整性的权利，不属于本公共许可授予的权利；公开权、隐私权和/或其他类似人格权也不在许可范围内。但是，在可能范围内，许可方放弃和/或同意不主张其所拥有的上述权利，但仅限于为使您能够行使被许可权利所必要的程度，除此以外不作放弃。

2. 专利权和商标权不在本公共许可范围内。

3. 在可能范围内，许可方放弃因您行使被许可权利而向您收取版税的任何权利，无论该版税是由许可方直接收取，还是通过集体管理组织依据自愿性、可放弃的法定许可或强制许可制度收取。在其他所有情况下，许可方明确保留收取此类版税的任何权利。

iv. 指向免责声明的声明；

v. 在合理可行范围内，提供许可材料的 URI 或超链接；

C. 说明许可材料依据本公共许可进行许可，并提供本公共许可的文本，或本公共许可的 URI/超链接。
